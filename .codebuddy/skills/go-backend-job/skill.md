# Go 后端开发求职技能包

## 目标岗位技能要求
- **核心栈**: Go + Gin + Gorm
- **数据库**: PostgreSQL（设计、优化、事务、联表查询）
- **缓存**: Redis（缓存策略、性能优化）
- **API**: RESTful API 设计与开发
- **加分项**: Docker、React、AI 平台对接

## 学习路线图

### 阶段一：Go 基础巩固（1-2周）
- 变量、数据类型、控制流
- 函数、结构体、接口
- 并发：goroutine、channel、select
- 错误处理、defer、panic/recover

### 阶段二：Gin 框架（1-2周）
- 路由定义与参数获取
- 中间件开发与使用
- 请求绑定与验证
- 响应渲染（JSON、HTML）
- 错误处理与日志
- 项目结构组织

### 阶段三：Gorm ORM（1-2周）
- 模型定义与迁移
- CRUD 操作
- 关联（一对一、一对多、多对多）
- 事务处理
- 钩子（Hooks）
- 性能优化（预加载、分页）

### 阶段四：PostgreSQL（1周）
- 与 MySQL 的差异
- 数据类型、索引
- 复杂查询、联表
- 事务隔离级别

### 阶段五：Redis（1周）
- 数据类型与应用场景
- 缓存策略（缓存穿透、击穿、雪崩）
- 分布式锁
- 性能优化

### 阶段六：项目实战（2-3周）
- 完整 RESTful API 项目
- 用户系统（注册、登录、JWT）
- 文章/商品 CRUD
- 评论系统
- 缓存优化
- Docker 部署

### 阶段七：面试准备（1周）
- Go 语言面试题
- 系统设计
- 项目复盘

## 教学原则
1. 优先用 PHP/Laravel 概念类比
2. 每学完一个模块必须有实战代码
3. 强调与 PHP 的差异点
4. 结合招聘要求，突出"能干活"
